# Zentro Moto Website

Working front-end prototype for the Zentro Moto ecommerce site, built from
the site's Website Structure & UX Plan brief. Static HTML/CSS/JS — no build
step required.

Zentro Moto sells three genuine Surron electric motorcycles, always in this
order: **Hyper Bee → Light Bee 2.0 → Ultra Bee**. Zentro Moto is an
independent Australian retailer and is not an authorised Surron distributor
or representative — this is reflected in the copy throughout the site.

## Previewing the site

No build tools needed — it's plain static files. From the project root:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/index.html`.

## What's a placeholder

Per the brief, no prices, specifications, warranty conditions or contact
details were supplied, so these are shown as clearly labelled placeholders
ready to be replaced:

- **Prices** — `$X,XXX`
- **Specifications** — `SPEC TO CONFIRM`
- **Business/contact details, legal terms, shipping/returns process detail**
  — `TO CONFIRM` / `PLACEHOLDER`
- **Product photography** — abstract line-art SVGs labelled "PLACEHOLDER
  IMAGE", in `assets/img/placeholders/`, ready to swap for licensed photos
  (see `scripts/gen_placeholders.py`)

Warranty, spare-parts and Australian Consumer Law wording is carried over
verbatim from the brief and kept consistent across every page that mentions
it.

## Pages

Home · Bikes · 3 product pages (one shared template) · About · Support/FAQ ·
Shipping & Collection · Warranty & Returns · Contact · Cart · Checkout
confirmation · Terms of Sale · Privacy Policy · Reservation/Order Terms.

Cart/checkout is a client-side (`localStorage`) prototype only — the live
build should run on Shopify's standard cart and checkout flow, per the brief.

## Regenerating pages

All page markup is generated from `scripts/build.py` so copy, structure and
components (header, footer, bike data, warranty wording, etc.) stay
consistent across every page. To change site copy, edit the data/content in
`scripts/build.py` and re-run:

```bash
python3 scripts/build.py
```

Placeholder imagery is generated by `scripts/gen_placeholders.py` — re-run it
if you add new shots or models; it won't overwrite files you've manually
replaced with real photography as long as you rename them or update the
references in `scripts/build.py` accordingly.

## Structure

```
assets/css/styles.css   Design system (typography, layout, components)
assets/js/main.js       Cart, nav, gallery, FAQ, forms — all client-side
assets/img/placeholders/  Placeholder SVG imagery
scripts/build.py         Generates every HTML page
scripts/gen_placeholders.py  Generates placeholder imagery
*.html                    Generated pages (safe to hand-edit, but changes
                           will be overwritten by the next `build.py` run)
```
